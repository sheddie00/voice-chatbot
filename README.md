# Voice Chatbot

A **voice-enabled chatbot** built with Python and Streamlit. This chatbot can take **text or voice input**, process it, and respond in real-time. It uses **speech recognition** to convert your voice to text and **text-to-speech** to speak responses aloud.  

---

## Features

- Accepts **text input** via a text box.
- Accepts **voice input** via a microphone.
- Responds using a **retrieval-based chatbot algorithm** with TF-IDF similarity.
- **Text-to-speech**: chatbot can speak its responses.
- Maintains **conversation history** in the Streamlit app.
- Built with **Python, Streamlit, NLTK, scikit-learn, SpeechRecognition, and pyttsx3**.
